# assets

| File | Use |
|------|-----|
| `resume_search_icon.svg` | The square app icon, used everywhere in the app (embedded as a data URI). |
| `resume_search_icon_512.png` | PNG fallback when the SVG is unavailable. |
| `resume_search_favicon_64.png` | Browser-tab icon (`st.set_page_config(page_icon=...)`). |
| `resume_search_logo.png` | Icon plus name, used at the top of the README only. |

Never stretch, recolour or crop the icon, and keep at least 16 px of clear space around it.
